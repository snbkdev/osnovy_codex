# Uptime Toolkit — локальный персональный плагин

Пакет: `plugins/uptime-toolkit`, версия `0.1.0`. Включает пять проектных скиллов и их вспомогательные файлы. Исходники: `.codex/skills/`; копии адаптированы для установленного плагина. При обновлении исходников перенесите изменения и увеличьте версию в обоих манифестах.

Персональный маркетплейс устанавливается в `~/.agents/plugins/marketplace.json`, пакет — в `~/plugins/uptime-toolkit`. Другие записи маркетплейса сохраняются.

После установки откройте новую задачу в каталоге uptime_app и выберите Uptime Toolkit. Пример: «Используй uptime-toolkit:standup, подготовь сводку за вчера». Браузер запускается только по явному запросу.

Скрипты скиллов запускаются из каталога приложения или с `--root /path/to/uptime_app`. Плагин не включает MCP-сервер и не устанавливает Go, npm или Playwright.

Повторная установка после изменения версии:

```sh
codex plugin add uptime-toolkit@asanbek-personal
codex plugin list --marketplace asanbek-personal --json
```

В проекте также доступны исходные скиллы: для проверки плагина выбирайте именно скилл с префиксом `uptime-toolkit:`.
